# BERSERK Cyber Club

Одностраничный сайт компьютерного клуба BERSERK (Москва, Кастанаевская ул., 41, корп. 2).

- `site/` — готовый статический сайт: `index.html`, `css/`, `js/`, `images/`, `fonts/`. Сборка не нужна, папку можно сразу выложить на хостинг.
- Корень — исходные фото клуба.

Сайт опубликован на GitHub Pages: https://yabujin1337.github.io/berserk/ (автоматически при каждом пуше в main). При переезде на свой домен замените `https://yabujin1337.github.io/berserk` на него в `site/index.html`, `site/robots.txt` и `site/sitemap.xml`.

CSS правится в `site/css/style.css`, страница подключает сжатую копию `site/css/style.min.css`.
